Innocent strings the public-hygiene gate must stay silent on.
=============================================================

This file is tracked, so scripts/check-public-hygiene.sh scans it like any other
file in the tree. That is the whole point: every line below looks enough like a
private planning identifier to be a plausible false positive, and if a pattern
is ever loosened until it bites one of them, the gate goes red on its own
fixture instead of on somebody's honest prose six months later.

Add a line here whenever a pattern is tightened, so the tightening stays fixed.
Never add a line that is a genuine violation — this file is not an allowlist.
The allowlist is scripts/public-hygiene-allowlist.txt and it is exempt from the
scan; this file deliberately is not.

Kebab-case runs below the card-slug threshold
----------------------------------------------
Five hyphen-joined words is one segment short of the six the card-slug rule
requires. Most real titles run eight or more, but roughly one in eight runs six
or seven, so six is a floor with little room above it.

    alpha-bravo-charlie-delta-echo is a five-segment placeholder
    a form-n-cen-data-set is SEC filing vocabulary, not a card title

Strings the path rule must never read as a repository path
------------------------------------------------------------
One caveat before the list. Every other section here is true anywhere, but the
cross-repo-doc-path rule asks whether a `.md` path is rooted in THIS repository,
so whether a path is innocent depends on the repository around it — and this file
is scanned twice, once in the real tree and once inside the synthetic repo the
self-test builds, and the two have different directories at their roots. Only
tree-INDEPENDENT cases belong here. The tree-dependent ones live in
scripts/check-public-hygiene-selftest.sh, which states the repository it builds
and so can say what "inside" means.

A URL is tree-independent: every position a match could start at is preceded by
`/`, `.` or `:`, all of which the pattern refuses.

    https://example.com/docs/guide.md
    https://raw.githubusercontent.com/example/repo/main/README.md
    see [the guide](https://example.com/handbook/getting-started.md)

MIME types and module paths are what the rule would swallow if the `.md`
requirement were ever dropped as "too narrow". It is not too narrow; it is the
only thing standing between this rule and every slash in the tree.

    application/vnd.apache.parquet
    text/csv, application/json, image/svg+xml
    the std::collections module path, and serde/serde_json in prose

An interpolated path has a variable name where its root segment should be, so
nothing can be decided about where it points. These were not hypothetical: the
first draft of the rule turned red on this repository's own self-test.
